# 邮件活动离线预览台

计划管理邮件活动内容、收件人分组和离线预览。面向本地单机使用，采用 Python 3 标准库与 SQLite。

## 离线预览

读取联系人 CSV 与文字模板，按 segment 单值筛选，生成逐人文本预览与 JSON 报告（不发送邮件）：

```sh
python -m newsletter_preview --contacts contacts.csv --template template.txt --segment newsletter --out previews
```

- 可选的 `--format` 选择逐人预览格式，仅接受 `text` 与 `html`，省略时为 `text`：`text`（显式给出或省略）保持上述文本预览，输出与既有版本逐字节一致；`html` 时逐人预览改名为 `preview-0001.html` 起连续编号（不生成 `.txt` 副本，目录中只有这些 HTML 文件和 `report.json`），报告 `previews` 清单中的 `file` 同步改为实际 HTML 文件名，其余结构、计数、邮箱与顺序含义不变。
- HTML 预览是声明 UTF-8（`<meta charset="utf-8">`）的完整文档，正文用一个 `pre` 元素展示，不引用任何网络资源。变量仍按既有规则替换、字段值不再次解析；模板与字段值中的 `&`、`<`、`>`、标签及实体样式文字均按字面显示（HTML 转义），不会成为页面元素；中文、空格、空行以及正文开头和末尾的换行都保留。
- 可选的无值参数 `--index` 在输出目录额外生成 `index.html`：一份声明 UTF-8 的完整离线 HTML 文档，显示筛选值与分组命中、排除、最终预览三个记录数（与 `report.json` 一致）。页面先按 CSV 顺序逐条列出保留记录的原始姓名、邮箱及预览链接；共享邮箱的每条记录分别列项。链接只写同目录预览文件名（text 格式为 `.txt`、html 格式为 `.html`）这一相对地址，整个输出目录移动后仍可打开；邮箱仅显示为文字（无 `mailto:`），页面不引用任何网络资源，姓名、邮箱与筛选值中的中文、`&`、尖括号、引号及 `{{name}}` 样式文字均按字面显示（HTML 转义），保留大小写与首尾空白；这些值的普通空格（U+0020）不仅在源码中保留，也在浏览器的实际排版中按原数量显示——首尾空格与内部连续空格均不折叠（页面在 `head` 内嵌一段本地样式，对筛选值段落及两个清单的姓名、邮箱单元格应用 `white-space: pre-wrap`，表头与“预览”链接单元格维持普通排版），实现方式是该 CSS 预排版规则本身，既不修剪任何输入空格，也不替换为 `&nbsp;` 等可见标记（可在浏览器中直接核对首尾与连续空格数量）。保留联系人清单之后是“已排除的联系人”区域：逐条显示被排除记录的原始姓名和邮箱（仅文字，无预览或邮件链接），区域内容及顺序与 `report.json` 的 `excluded_contacts` 完全一致，条目数等于 `excluded_count`——只包含命中分组后被排除名单（`--exclude-email` 与 `--exclude-file`）移除的记录，未命中分组的记录不出现；共享邮箱的记录各列一项，重复的排除值不重复增加条目。没有排除记录（含零命中）时该区域显示“没有被排除的联系人”。默认 text 格式与 `--format html` 的索引页具有相同的排除区域。省略 `--index` 时不生成该文件，且逐人预览与 `report.json` 与同输入、同格式但未开启时逐字节一致——索引页是唯一新增文件。零命中或全部排除时同样退出 0，只生成 `report.json` 与 `index.html`，页面保留三个计数：零命中时“没有可预览的联系人”与“没有被排除的联系人”两个空状态同时出现；全部排除时保留“没有可预览的联系人”提示、页面不含任何预览链接，但“已排除的联系人”区域仍列出全部排除条目。

- CSV 为 UTF-8：文件开头、首行之前允许带一个 UTF-8 BOM（字节 EF BB BF），该标记仅作编码声明，读取时忽略，带与不带 BOM 的同一文件结果完全一致；仅文件开头的一个 BOM 享受此处理，字段内部的 U+FEFF 属于正文，原样保留且不修剪。首行表头须含 `name`、`email`、`segment`（列顺序不限，额外列忽略）。模板文件不做 BOM 处理，其内容（含任何位置的 U+FEFF）均按正文原样保留。
- 模板仅支持 `{{name}}`、`{{email}}` 与 `{{segment}}` 变量（可混合或重复出现，取当前记录的原始字段值，`{{segment}}` 为该记录 segment 列的原文、保留大小写与首尾空白；替换值不再次解析）；其他 `{{...}}` 占位符视为未知变量。
- 可选的 `--exclude-email` 可重复提供，每次一个邮箱：匹配记录中 `email` 与任一排除值完全相同（区分大小写、不修剪空白）的记录将被移除；共享邮箱的匹配记录全部排除，其他重复邮箱各自保留。排除值为空或仅含空白时退出 2。
- 可选的 `--exclude-file`（每次一个文件路径，可与 `--exclude-email` 同时使用）从 UTF-8 本地名单文件追加排除邮箱：文件无表头、每行一个邮箱，支持 LF 与 CRLF 行结束、末行无换行；空行及仅含空白的行忽略，其他行只移除行结束符，保留大小写与首尾空白（名单文件不做 BOM 处理，开头的 U+FEFF 属于正文）；空文件视为空名单。文件名单与命令行名单合并去重后按邮箱原文精确匹配，共享邮箱的命中记录全部排除，重复值（无论来自命令行还是文件、出现几次）不叠加计数，未命中的值不影响结果；全部由文件名单产生的排除与等价的 `--exclude-email` 命令行输出逐字节一致。文件不存在、不可读或 UTF-8 解码失败时退出 2，标准错误包含路径与原因且无 Traceback；`--exclude-file` 缺值同样退出 2 并点名该参数。名单文件在创建输出目录之前读取校验，因此失败时尚不存在的输出目录不会创建，已存在的空目录保持为空；零命中也要成功读取名单文件。省略该参数时输出与既有版本逐字节一致。
- 输出目录不存在时创建，存在时须为空；逐人预览按保留记录的 CSV 顺序自 `preview-0001` 起连续编号（扩展名随 `--format`：text 为 `.txt`、html 为 `.html`，不因排除留空号），另生成 `report.json`（含模板原文、筛选值、排除前的分组命中记录数 `segment_count`、被排除名单（`--exclude-email` 与 `--exclude-file`）移除的记录数 `excluded_count`、被移除记录的明细 `excluded_contacts`（按 CSV 顺序逐项列出原始 `name` 与 `email`，共享邮箱的每条命中各列一项）、最终预览人数 `matched_count` 与预览清单；计数均按 CSV 数据记录统计，不按唯一邮箱）。
- 成功退出 0；输入校验失败、输入不可读、参数不合法或输出目录非空/不可写时退出 2，且不创建任何输出。写入阶段失败（含 `index.html` 写入失败）同样退出 2，标准错误点名文件与底层原因，但此前已写出的预览与报告允许保留，不回滚；输出目录非空时拒绝运行且其中原有文件原样保留。
